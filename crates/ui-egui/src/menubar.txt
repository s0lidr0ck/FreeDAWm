// The menu bar as shown (after the hand-built FreeDAWm menu), top to bottom. The incumbent's
// catalog (crates/engine/catalog/menus.txt) stays the parity list; this file decides what is shown
// and where. Same line format as the catalog, `Menu > Submenu > Item`, extended:
//
//   Menu > Sub > Item                 a leaf run through that same catalog/UI path
//   Menu > Sub > Item = Other > Path  a leaf shown here, run through another catalog/UI path
//   Menu > Item = @command.id         a leaf that runs a command id directly
//   Menu > ## Heading                 a small group heading
//   Menu > ---                        a separator
//   Menu > Item = soon                shown greyed out, hover "Coming soon: needs its own window"
//   Menu > Item = soon: Text          shown greyed out, hover "Text"
//   Menu > Item = !instrument         built by the UI (!instrument, !recent)
//   ... [desktop]                     left out of the web build
//
// Submenus are made by the path; lines of one submenu need not be adjacent, but keep them so.
// Labels ending in "..." or "…" open a dialog or window (a test checks it).
